# gestiona-informacion-mediante-el-uso-de-software-en-linea
para el uso de investigacion para la materia gestiona informacion mediante el uso  de software en linea
Características principales de GitHub
Control de versiones
Permite registrar cambios en archivos y recuperar versiones anteriores fácilmente mediante Git.
Repositorios remotos
Los proyectos se almacenan en línea en repositorios públicos o privados.
Trabajo colaborativo
Varias personas pueden trabajar simultáneamente en un mismo proyecto usando ramas (branches) y fusiones (merge).
Pull Requests
Facilita revisar, comentar y aprobar cambios antes de integrarlos al proyecto principal.
Issues y gestión de tareas
Incluye herramientas para reportar errores, proponer mejoras y organizar trabajo.
GitHub Actions
Automatiza pruebas, despliegues y procesos de integración continua (CI/CD).
Documentación integrada
Uso de archivos README, Wikis y páginas web con GitHub Pages.
Integración con otras herramientas
Compatible con IDEs, servicios de nube, plataformas DevOps y herramientas de automatización.
Seguridad y control de acceso
Permite gestionar permisos, autenticación y análisis de vulnerabilidades.
Ventajas de GitHub
1. Facilita el trabajo en equipo
Permite colaboración ordenada entre múltiples desarrolladores sin sobrescribir trabajo ajeno.
2. Historial completo de cambios
Cada modificación queda registrada, lo que ayuda a rastrear errores y recuperar versiones.
3. Respaldo en la nube
El código queda almacenado de forma segura y accesible desde cualquier lugar.
4. Popularidad y comunidad
Es una de las plataformas más usadas del mundo, con millones de proyectos de código abierto.
5. Integración con DevOps
Automatiza compilaciones, pruebas y despliegues mediante GitHub Actions.
6. Portafolio profesional
Muchos reclutadores revisan perfiles de GitHub para evaluar habilidades técnicas.
7. Gratuito para muchos usos
Ofrece planes gratuitos con repositorios privados y herramientas suficientes para estudiantes y pequeños equipos.
Desventajas de GitHub
1. Curva de aprendizaje
Git y GitHub pueden resultar complejos para principiantes.
2. Dependencia de internet
Aunque Git funciona localmente, muchas funciones de GitHub requieren conexión.
3. Riesgo de exponer información
Un repositorio público mal configurado puede revelar código o datos sensibles.
4. Limitaciones en planes gratuitos
Algunas funciones avanzadas de seguridad, automatización o administración requieren pago.
5. Conflictos de versiones
Cuando varias personas modifican el mismo archivo pueden surgir conflictos de fusión.
6. Dependencia de una plataforma externa
Si GitHub presenta fallas o cambios en políticas, los proyectos pueden verse afectados.
